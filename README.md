# Global-Superstore_Mini-Project
This mini project focuses on Global Superstore Sales Analysis using Power BI and supporting datasets. It aims to explore sales performance, profitability, customer segmentation, and market insights through interactive dashboards and data modeling.
# Folder Contain:
Global_Superstore CSV: Raw CSV version of the dataset for import flexibility and data validation.
Global_Superstore: Cleaned and structured Excel dataset containing sales, profit, and customer details used for Power BI modeling.
Mini_ Project: Power BI report file containing dashboards such as Global Profit Pulse and Market Momentum Tracker. Includes visuals for regional sales, category performance, and executive insights.
Mini_Project_Document: Documentation file summarizing project objectives, methodology, insights, and strategic recommendations derived from the Power BI analysis.
# Tools & Technologies
Microsoft Power BI — Dashboard creation and data visualization.
Microsoft Excel / CSV — Data cleaning and preparation.
Microsoft Word — Documentation
